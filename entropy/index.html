第一次在这台设备使用
这个移动版不会内置你的私人清单。请先在电脑端导出一个 JSON 备份，再在这里导入。 导入后，数据只保存在这台设备的浏览器里，不会上传到云端。
导入完成后，可用浏览器菜单“添加到主屏幕 / 安装 App”。iPhone 请用 Safari 的分享菜单。

数据备份 · BACKUP
把当前全部清单与历史导出成真实文件。备份文件保存在浏览器之外， Chrome 更新、清除缓存或 localStorage 异常都不会删除它。
推荐保存到：文档\Entropy Backups、OneDrive / Dropbox 同步文件夹， 或移动硬盘。不要把唯一备份放在 Chrome 的 User Data 目录里。
“合并备份”适合把旧版本中继续使用产生的新数据并入当前版本； “从备份恢复”会整体替换当前数据。备份文件带时间戳，不会自动覆写旧备份。
