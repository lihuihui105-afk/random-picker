Entropy Mobile / PWA 使用说明
=============================

这个版本没有云同步，也没有把你的私人清单写进网页源码。
每台设备的数据各自保存在该设备浏览器的 localStorage 中。

第一次使用：
1. 在电脑端打开你正在使用的 Entropy v10（或更新版本）。
2. 点“备份到文件…”或“快速下载备份”，得到 JSON 文件。
3. 把本文件夹完整上传到一个支持 HTTPS 的静态网站空间。
   必须一起上传：index.html、manifest.webmanifest、service-worker.js、两个 icon PNG。
4. 用手机浏览器打开网站地址。
5. 第一次打开会出现提示，选择“导入我的备份”，导入电脑导出的 JSON。
6. 导入后：
   - iPhone/iPad：Safari → 分享 → 添加到主屏幕。
   - Android：Chrome/浏览器菜单 → 安装应用 / 添加到主屏幕。

日常数据：
- 添加、删除、抽取都会自动保存到当前手机浏览器。
- 不会自动同步到电脑，也不会上传到云端。
- 想把手机数据带回电脑时，在手机里导出 JSON，再到电脑端“合并备份”或“从备份恢复”。
- 建议仍定期导出 JSON 备份。

标签添加时间：
- 电脑：鼠标悬停标签。
- 手机：长按标签约半秒。
- 老数据若当时没有记录添加时间，会显示“旧数据 · 时间未知”。

离线：
- 通过 HTTPS 正常打开并成功安装/缓存后，主要页面可离线使用。
- Google 字体离线时可能回退到系统字体，不影响数据和随机功能。

隐私提醒：
- 这个 PWA 包本身不含恢复出来的私人清单。
- JSON 备份包含你的实际清单，请当作私人文件保存。
